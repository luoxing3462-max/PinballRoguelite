# Validation Module

- Assets/Tests/EditMode/CoreTests.cs covers deterministic tower generation, progression, split-score carryover, accumulation from multiple effective bumper collisions, portrait camera coverage for 750×1334, 780×1688, 1080×2400 and 1440×3200, and safe-area anchor calculation.
- Assets/Tests/PlayMode/GameplayFlowTests.cs verifies all four seeded staggered-grid templates, the default 4×4 12 normal/4 split allocation, equal row/column spacing, half-step row offsets, rotational coverage, configurable even counts, clearance and non-overlap; eight score slots and seven dividers; the 2 ×1, 1 ×0, 5 random rule distribution; visible labels; random ×2～×5 results; true zero settlement; one damage event per bumper despite repeated contact with the same bumper; isolated GameplayUI.prefab instantiation, its required stable hierarchy, victory/defeat presentation and callback wiring; and a complete physical launch/combat flow.
- Assets/Editor/ProjectBuilder.cs regenerates UI.prefab and supplies broader validation/build automation. Assets/Editor/PlayModeStartupScene.cs uses Unity's editor-only `playModeStartScene` hook so the normal Play button always runs Assets/Scenes/Main.unity instead of an open scratch scene.
- Assets/Editor/WebGlBuild.cs is the explicit WebGL/GitHub Pages export entry point. It validates the installed WebGL module, builds `Main.unity` into `Builds/WebGL`, and writes `.nojekyll` only after a successful export. The Pages workflow deploys that retained output; it does not rebuild Unity on GitHub.

For UI-root changes, verify the prefab contains Canvas and EventSystem components and that runtime screens attach successfully. For combat or settlement-row presentation changes, verify the affected states at the 540×960 editor size and 1080×1920 design size. For board-layout, collider, scoring-slot, damage-award, or launch-route changes, run the focused PlayMode acceptance covering layout invariants, score rules, labels, per-bumper gating, and a physical shot. Add or change a maintained test only when the requested behavior lacks coverage.
